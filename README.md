# image-merging

横方向へ分割された2〜4枚の画像ファイルを自動解析し、ブラウザ内で元の1枚へ復元するツールです。

## セルフホストする場合

`index.html` をブラウザで開くか、このフォルダで静的Webサーバーを起動してください。画像処理はすべてブラウザ内で行われ、画像は外部へ送信されません。

### Cloudflare Pagesへの公開

`_headers` も含めて公開してください。HTMLは端末に保存せず、CSSとJavaScriptは更新の有無を毎回確認する設定です。CSSまたはJavaScriptを更新したときは、`index.html` 内の `?v=20260904-2` を新しい番号へ変更すると、すでに端末へ残っている古いファイルを確実に回避できます。

## MVPの機能

- PNG / JPEG / WebP画像2〜4枚の同時アップロード
- 枚数の自動判定
- 「自動で並べ替え (Beta)」を押した場合のみ自動解析
- ファイル名の連番を優先した高精度な並び替え
- 連番がない場合は左右32pxの画像帯から、色・輪郭・線の方向を複合解析
- ドラッグによる手動修正
- 画像高さの自動統一（最大高さまたは最小高さ）
- 境界のクロスフェード合成と幅調整
- 高解像度プレビューとPNG保存
- iPhone / iPadでは共有メニューから写真Appへ保存（「画像を保存」を選択）
